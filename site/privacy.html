Privacy Policy

Context Hypervisor — Prompt Compiler (Chrome extension)

Last updated 5 October 2026

The short version. Everything this extension stores stays on your own computer. There is no account, no server belonging to the developer, no analytics and no tracking. The only time anything leaves your browser is when you press a button to send a prompt to an AI service you chose and signed up for yourself, and the only thing sent is the prompt you can read on screen before you send it.

Who this is from

Context Hypervisor is developed and published by Pushkal Gupta as an independent project. Questions about this policy can be raised as an issue on the project's rule registry at github.com/AHosting/Space-Tyles-Rules.

What the extension does

It reads the page you are looking at, takes from it only the parts that the rule you selected asks for, and assembles those into a prompt. You then choose what to do with that prompt: copy it, open it in an AI service you are already logged in to, or send it through an API key you supplied.

What is stored, and where

All of the following is kept in Chrome's local extension storage, on your device. None of it is transmitted anywhere by the extension. Uninstalling the extension deletes all of it.

WhatWhyWhere it goes
API keys you enter So the extension can call the AI provider you chose on your behalf Your device only. Sent solely to the provider that issued the key, as that provider's API requires.
Rules and drivers you install They define what gets read from a page and how the prompt is worded Your device only.
Activity history — the address and title of a page you ran a rule on, whether it was a PDF, and how many images you attached So you can see and review what the extension has read on your behalf Your device only. Clearable from the Activity page at any time.
Saved prompts So you can reuse a prompt you compiled earlier Your device only.
Preferences — your chosen provider and model, which rule you last used on a site, panel settings So the extension behaves consistently between visits Your device only.

Page content itself is not stored. It is read when you ask for a prompt, used to build that prompt, and discarded. Only the prompt you explicitly save is kept.

What leaves your browser

1. The prompt, to the AI service you picked — only when you press send

Depending on your choice, the prompt is sent to one of:

  • api.anthropic.com (Anthropic)
  • api.openai.com (OpenAI)
  • generativelanguage.googleapis.com (Google)
  • or it is typed into a tab you already have open and are already signed in to, at chatgpt.com, claude.ai or gemini.google.com

What is sent is the prompt shown in the panel, plus any image or screenshot you attached. Because a prompt is built from the page you are on, it can contain text from that page — that is the purpose of the extension. The prompt is fully visible and editable before you send it, and nothing is sent automatically or in the background.

Once the prompt reaches an AI provider, that provider's own privacy policy and terms govern what happens to it. This extension has no control over, and no visibility into, their handling of it.

2. A request for the rule catalogue

When you open the rule library, the extension fetches a static JSON catalogue from ahosting.github.io, which is GitHub Pages. This is an ordinary file download. It contains no information about you, the page you are on, or what you have installed. As with any web request, GitHub receives the network-level metadata it would receive for any visit to a web page, such as your IP address; GitHub's privacy statement governs that.

3. Nothing else

There are no analytics, no crash reporting, no advertising, no tracking pixels and no developer server. The extension makes no network request other than the two described above.

What is never done

  • Your data is never sold, rented or shared with data brokers.
  • Your data is never used to build advertising or marketing profiles.
  • Your data is never transmitted to the developer, who operates no server that could receive it.
  • Nothing is read from a page except when you ask for a prompt on that page.
  • No credentials, cookies or session tokens from the sites you visit are read, copied or stored.

Why the extension asks for access to all sites

A prompt is compiled from whatever page you happen to be on, and a rule can be written for any site, including one installed long after the extension was. There is no list of sites that could be declared in advance without deciding for you which pages the tool is allowed to help with.

Access is used only in response to something you do: selecting a rule, pressing a button, or picking an element. The extension does not read or transmit anything from a page you have not acted on.

Children

This extension is a developer and productivity tool. It is not directed at children, and it collects nothing that would identify anyone.

Changes to this policy

If what the extension does with data changes, this page changes with it and the date at the top is updated. Material changes will also be described in the extension's Web Store listing.
